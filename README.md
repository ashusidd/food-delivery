## React Compiler

The React Compiler is not enabled on this template because of its impact on dev & build performances. To add it, see [this documentation](https://react.dev/learn/react-compiler/installation).

# 🍔 Food Delivery App (Gaon Swad)

A modern, fast, and interactive Food Delivery Web App built using **React.js**. This app features a seamless ordering experience with WhatsApp integration and haptic feedback.

## 🚀 Key Features

* **🛒 Advanced Quantity Management:** Users can add, increase, decrease, or remove items directly from the food cards or the cart.
* **📳 Haptic Feedback (Vibration):** Integrated vibration triggers on button clicks for a premium mobile-app feel.
* **🍱 User-Specific Cart:** Cart data is linked to the user's phone number, ensuring unique carts for different users.
* **🖼️ Smart Image Handling:** Automatic backup images for broken links to maintain a clean UI.
* **✨ Glassmorphism UI:** Modern, floating navbar and translucent login/signup forms.
* **📲 WhatsApp Ordering:** Direct order placement via WhatsApp with full bill details and address.

## 🛠️ Tech Stack

* **Frontend:** React.js, CSS3 (Modern Flexbox/Grid)
* **State Management:** React Context API
* **Storage:** LocalStorage (User-linked)
* **Icons:** Lucide-React / FontAwesome
